# dsh-codex-migrate v2.0.3

Reliable compatibility with the public npm `@deepseek-ai/dsh` 0.1.5 release line, plus a complete DSH-to-Codex handoff fix for browsers that block custom protocol navigation.

## Highlights

- Adapt Codex-to-DSH imports to lifecycle-scoped `SessionHandle` persistence and valid Session V3 event streams.
- Update the Web client injection graph and peer ranges for the modules shipped by DSH 0.1.5.
- Fix “Continue in Codex” so it imports the active DSH conversation rather than a message identifier.
- Open imported Codex tasks through the host operating system, with browser navigation retained as a fallback.
- Bound inventory metadata reads and move full transcript reads off the synchronous scan path, keeping large-history refreshes responsive.
- Keep Windows cleanup tolerant of short-lived file locks after a successful Codex import.

## Supported DSH target

This release is verified against npm `@deepseek-ai/dsh@0.1.5-rc.2` (`latest` on 2026-09-20). GitHub-only `0.1.6-alpha.2` is a developer preview and is not claimed as a supported runtime by this release.

## Install or update

```powershell
dsh plugin --profile web add dsh-codex-migrate@2.0.3
```

Existing installations can update with:

```powershell
dsh plugin --profile web update dsh-codex-migrate
```

Restart DSH after installation or update.
