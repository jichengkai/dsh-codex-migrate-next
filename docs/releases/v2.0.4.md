# dsh-codex-migrate v2.0.4

This is a documentation and version-metadata release on top of v2.0.3. It makes the DSH compatibility statement available in both READMEs included in the npm package. There are no new migration behavior changes in v2.0.4.

## Compatibility carried forward

- Codex → DSH imports use lifecycle-scoped `SessionHandle` persistence and valid Session V3 events, with a legacy persistence fallback.
- The Web client injection graph matches the DSH 0.1.5 modules, and “Continue in Codex” uses the active conversation's session ID.
- Bounded inventory metadata reads and asynchronous transcript reads reduce stalls with large histories.
- Imported Codex tasks open through the host operating system when browsers block `codex://`, with browser navigation retained as a fallback.

The verified target is the public npm `@deepseek-ai/dsh@0.1.5-rc.2` (`latest` on 2026-09-23). The npm `next` and `alpha` channels are not claimed as supported. See [v2.0.3](./v2.0.3.md) for the original fix details and verification history.

## Install or update

```powershell
dsh plugin --profile web add dsh-codex-migrate@2.0.4
```

Existing installations can use `dsh plugin --profile web update dsh-codex-migrate`. Restart DSH afterward.
